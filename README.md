# 差旅通 · 出差行程规划

一款轻量的纯前端出差规划工具。无需后端、无需构建，直接用浏览器打开 `index.html` 即可使用。所有数据保存在浏览器本地存储（localStorage），不会上传到任何服务器。

## 功能

- **仪表盘**：当前行程概览，出发倒计时、预算使用进度、即将进行的日程、全部行程快速切换。
- **行程管理**：创建 / 编辑 / 删除出差行程（主题、目的地、起止日期、预算、备注），一键切换当前行程。
- **日程安排**：按天编排航班、火车、住宿、会议、餐饮等事项，时间轴展示。
- **费用预算**：按类别记账，实时对比预算、显示结余与超支预警，分类占比一目了然。
- **行李清单**：可勾选的行李 / 待办清单，内置常用物品一键添加，完成进度可视化。

支持移动端自适应与深色模式。

## 使用

直接打开 `index.html`，或用任意静态服务器托管：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 技术说明

- 原生 JavaScript（ES Modules），零运行时依赖。
- 视图模块位于 `js/views/`，每个模块导出 `{ id, title, subtitle, render(container, ctx) }`。
- 数据层 `js/store.js` 统一负责状态与本地持久化。
- 首次打开会自动生成一条示例行程，方便快速上手；可在仪表盘「清空全部数据」重置。
