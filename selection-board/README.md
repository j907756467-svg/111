# 选品立项 PPT 看板 (Amazon Product-Selection Project-Initiation Board)

一个**可视化的亚马逊选品立项 PPT 看板**，根据 5 个技能包（产品概要 / 看市场 / 看竞争 / 定产品 / 完整工作流）生成，内置**本地数据存档**功能。

纯静态前端，零第三方依赖（图表为手写 SVG），可直接部署到 GitHub Pages 或任意静态服务器。

## 打开方式

**方式一 · 单文件版（最简单，无需服务器）**
直接双击 [`standalone.html`](standalone.html)，浏览器即可打开（CSS 与全部 JS 已内联，支持 `file://`）。
适合本地查看、邮件 / 微信分享、离线演示。

**方式二 · 多文件版（开发用，需 HTTP）**
分模块版本使用 ES Modules，需经 HTTP 访问：

```bash
# 在仓库根目录
python3 -m http.server 8099
# 浏览器打开 http://localhost:8099/selection-board/
```

> 修改 `js/` 或 `css/` 后，运行 `node selection-board/build-standalone.mjs` 重新生成单文件版。

## 功能

### 📊 可视化 PPT（23 页 · 覆盖 9 章工作流）
- **封面**：项目信息 + 3 个人工确认决策门（己品品牌 / 主攻细分 / 产品方向）
- **工作流总览**：九步流程图与全局锁定规则
- **第 1 章 产品概要**：产品定义、四大细分（环形图）、核心参数、关键词体系
- **第 2 章 看市场**：6 大 KPI、月度趋势（折线图）、价格/CFM/sone 分布、细分优先度 + 确认门
- **第 3 章 看竞争**：品牌 TOP10、竞品产品线热力矩阵、竞品公司分析、标杆父体拆解
- **第 4 章 看用户**：VOC 好评/差评占比、sone 参数临界值
- **第 5 章 看自己**：己品产品线、供应链、SWOT 四象限
- **第 6 章 定产品**：SWOT 交叉推导、3 方向定义 + **7 维产品力雷达图**、产品定义表、专利排查
- **第 7 章 定策略**：成本结构、毛利率/ROI 仪表盘、盈亏平衡
- **第 8 章 定计划**：开发周期甘特图
- **第 9 章 立项评审**：立项九问、加权评分矩阵、Go / NoGo 决策

两种视图：**▦ 看板**（全部缩略图总览）与 **▶ 演示**（全屏单页 + 键盘 ← →）。

### 🗂 数据存档
- **当前数据自动缓存**到浏览器 localStorage
- **命名快照**：随时保存当前报告为存档，一键恢复 / 重命名 / 删除
- **导入 / 导出 JSON**：导出当前报告或整包（含全部存档），可跨设备迁移
- **恢复默认数据**
- **点击任意字段即可编辑**（标题、品牌、参数等），改动自动落盘

### 🖨 导出 PDF
浏览器打印为 16:9 PPT 版式 PDF（每页一张幻灯片）。

## 数据来源

默认数据为**亚马逊浴室排气扇**品类、己品品牌 **Amico**，数值取自技能包中的示例（如带灯款
$4,579 万占比 50.5%、智能款增速 +76% 等）。所有数据均可在看板中编辑后存档，替换为你自己的品类与数据。

## 文件结构

```
selection-board/
├── index.html              # 多文件版页面外壳
├── standalone.html         # 单文件版（CSS+JS 全内联，可双击 / file:// 打开）
├── build-standalone.mjs    # 由多文件构建单文件版的脚本
├── css/board.css           # 主题样式（PPT 版式 / 图表 / 抽屉 / 打印）
└── js/
    ├── defaultData.js  # 默认数据集（基于技能包示例）
    ├── charts.js       # 手写 SVG 图表引擎（折线/柱/条/环/雷达/甘特/仪表）
    ├── store.js        # 状态管理 + 数据存档（localStorage / 快照 / 导入导出）
    ├── slides.js       # 9 章幻灯片构建器
    └── main.js         # 控制器（导航 / 编辑 / 决策门 / 存档抽屉 / PDF）
```
